# PrangArt Lab — Creative Studio Website

A premium one-page company profile for a creative studio agency focused on branding, illustration, motion, and digital experiences.

## Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the local dev server:
   ```bash
   npm run dev
   ```

3. Open the site in your browser:
   ```bash
   http://localhost:3000
   ```

## Production build

```bash
npm run build
npm run start
```

## Deployment
This project is ready to be deployed on Vercel.

1. Push the repo to GitHub.
2. Import the repository in Vercel.
3. Set framework preset to Next.js.
4. Deploy.

## Notes
- Content is intentionally editable via the component files in `app/page.tsx` and the sections under `components/`.
- The design uses a dark default palette with a premium editorial aesthetic and responsive layout.
- SEO metadata is defined in `app/layout.tsx`.
